The profile is stored as metadata plus one discovery entry per Home Assistant entity. `discovery` is the editable entity array; saving adds its count automatically. Topic tokens (`__STATE_TOPIC__`, `__CMD_TOPIC__`, `__RAW_ENTITY__`) are resolved by the base at publish time, so the profile survives MQTT topic/device-name changes. The base reboots after a successful save.
